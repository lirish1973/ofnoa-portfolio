תצוגת תיק עבודות טכנולוגית ומרשימה למעצבי אתרים — פני האתר שמוכרים.

== Description ==

תוסף עצמאי לחלוטין (ללא תלות ב-Elementor או ACF) שמציג את האתרים שבנית בצורה שגורמת לגולשים להתרשם ולקנות.

= מה יש בפנים =
* **סוג תוכן ייעודי** "תיק עבודות" (Custom Post Type) — כל פרויקט עם קישור לאתר החי, צילומי דסקטופ+מובייל, תיאור, אתגרים, טכנולוגיות, לקוח, שנה וצבע הדגשה.
* **4 מצבי תצוגה מרשימים:**
  1. מסגרות מכשירים (CSS) — דפדפן ריאליסטי + נייד לידו, מראה שהאתר רספונסיבי.
  2. יד מחזיקה נייד — נייד תלת-ממדי עם צילום המסך בפנים.
  3. Cinematic פרלקסה — רוחב מלא עם עומק וגרדיאנט.
  4. כרטיסי 3D tilt — הטיה לפי העכבר.
* **שכבת אפקטים:** נצנוצים / זיקוקים / קונסטלציה / זוהר אורורה (Canvas).
* **פריסות:** Bento, Grid, Masonry, Carousel.
* **עיצוב מלא:** תֵמה כהה/בהיר/אוטומטי, צבעים, גופנים, מרווחים, עיגול פינות, רוחב, עמודות, סגנון כרטיס.
* **RTL מלא**, נגישות (מקלדת, פוקוס, alt), ו-prefers-reduced-motion.
* **ביצועים:** תמונות WebP עצלות, אנימציות על transform/opacity בלבד, קנבס שנעצר מחוץ למסך.
* **עדכונים אוטומטיים מ-GitHub** (כמו ofnoa-cards / ofnoa-forms).

= שיבוץ =
שורטקוד: `[ofnoa_portfolio]`
או בלוק Gutenberg בשם "Ofnoa Portfolio".

דוגמאות:
`[ofnoa_portfolio mode="hand" layout="grid" columns="2"]`
`[ofnoa_portfolio mode="cinematic" sparkles_style="fireworks" limit="3"]`

== Installation ==
1. העלה את התיקייה `ofnoa-portfolio` אל `wp-content/plugins/` (או התקן את קובץ ה-ZIP דרך תוספים → הוסף חדש → העלאת תוסף).
2. הפעל את התוסף. ארבעה פרויקטי דוגמה אמיתיים ייווצרו אוטומטית.
3. עבור אל "תיק עבודות → עיצוב ותצוגה" כדי לכוונן.
4. הדבק `[ofnoa_portfolio]` בעמוד, או השתמש בבלוק.
